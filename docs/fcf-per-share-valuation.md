# Free Cash Flow Per Share valuation

## Purpose

`POST /api/v1/private/stocks/{ticker}/valuation/fcf-per-share` estimates fair value per share for a going concern. It reads Free Cash Flow Per Share (TTM) from the latest stored fundamentals, forecasts it for an explicit period, discounts it using Cost of Equity, and uses Gordon growth after that period.

```
cost of equity = BI rate + beta x equity risk premium
terminal value = next year FCF per share / (cost of equity - terminal growth)
```

`master_data.bi_rate` is maintained as percentage points in the admin UI and converted to a decimal for this calculation (`5.75` becomes `0.0575`). Beta is loaded from the ticker's Yahoo Finance `5y`/`1mo` record in `stock_betas`. Request rate assumptions remain decimal values.

If `growth_rate` is omitted, the API derives it as `ROE x (1 - DPS TTM / EPS TTM)`.

## Good fit

Use it as a first-pass valuation for established non-financial companies with positive, reasonably repeatable free cash flow and a credible going-concern business model. Compare the fair value with market price; do not treat one scenario as a precise target price.

## When to use another method

| Situation | Better primary method | Reason |
|---|---|---|
| Banks, insurers, financial institutions | FCFE, dividend discount, residual income, or excess return | Debt and working capital are operational, so ordinary free-cash-flow logic does not fit. |
| Early-stage, loss-making, negative-FCF companies | Scenario DCF, revenue/unit-economics model, or relative valuation | TTM FCF/share is not a reliable base. |
| Defined-life assets such as mines or concessions | Finite-life DCF with yearly cash flows and salvage value | A perpetual terminal value is inappropriate. |
| Asset-heavy businesses | Residual-income or P/B cross-check | FCF/share can miss value and return generated by the asset base. |
| Special dividends, buybacks, dilution | Normalize dividends and shares | DPS TTM/EPS TTM can distort retention-based growth. |

## Data contract to verify

The service reads `free_cashflow_per_share_ttm` from `perShare` and `return_on_equity_ttm` from `managementEffectiveness`, with compatibility fallbacks for older snapshots. Confirm scraper definitions, currency, split adjustments, and treatment of special dividends before using this result in a production recommendation.
